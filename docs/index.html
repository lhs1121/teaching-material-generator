教学材料生成工作台

填好信息 → 点「复制全文」→ 粘贴到 WorkBuddy 对话框，即可生成教案 / 课件大纲 / 说课稿三件套。

一、课程信息

整门课只填一次，各章节共用。带 * 为必填；不清楚的字段可留空，技能会在对话中与你确认。

二、章节清单

一行一个章节，整门课一次填完。「典型工作任务」说不出就留空——技能会先反推、批量列出让你确认，不会硬编。

序号 章节 / 主题 * 典型工作任务（可留空，由技能反推） 课时 操作
课时留空默认按 课时计

三、生成结果

下方文本会随填写实时更新。可直接编辑微调，再复制粘贴给技能。

粘贴后技能会先判定生成路径（岗位驱动 / 章节驱动），再逐章节生成三件套并自检铁律。多个章节会按顺序产出多组文件，请留意生成进度。

这个工作台只做一件事：把信息整理成规范文本。路径判定、典型工作任务反推，都交给技能在对话中完成——工作台不代替判断，避免两处结论打架。

所有数据只保存在本机浏览器（localStorage），不上传、不外发。换电脑或清缓存后需重填。
