# 职业教育编写规范（铁律）

本文件固化职业教育课程材料的编写标准，由 `teaching-material-generator` 的所有产物共同遵守。源于长期教材编写实践，是评审（精品课程、教学能力比赛、1号文）中一票否决项的对应防线。

---

## 1. 版本与文件命名

- **版本号**：每节/每份材料从 `V1` 起编；任何修改升版本号（`V1→V2→V3`），保留所有旧版本文件，绝不覆盖。
- **文件命名**：
  - 三件套（教案 / 课件大纲 / 说课稿）按产物类型命名：`<章节主题> 教案 V1.md`、`<章节主题> 课件大纲 V1.md`、`<章节主题> 说课稿 V1.md`；若关联能力图谱编码可前缀：`<编码> <章节主题> 教案 V1.md`。
  - 单能力点材料沿用：`<编码> <能力名称> V版本号.md`（如 `B-1-1 数据清洗 V1.md`）。
  - 编码建议沿用课程能力图谱的"专业→课程→模块→任务"四级编码（参见 `vocational-competency-map` 技能）。
- **过程文件保留**：每次批量生成/修改后，逐文件验证结构、格式、内容一致性，不丢过程稿。

## 2. 英文缩写标注

- 所有英文缩写**首次出现必须标注中文全称**，格式：
  `中文（English Full Name，简称XXX）`
- 示例：`顾客关系管理（Customer Relationship Management，简称CRM）`、`企业资源计划（Enterprise Resource Planning，简称ERP）`。
- 同一缩写在同一文档内仅首次标注一次，后续可直接用简称。
- **逐文件独立自检**：三件套是三份独立文档，每份须**各自**执行首次全称标注。教案已标注，不替代课件大纲与说课稿的标注责任（实测中此处最易漏）。

## 3. 禁用教师视角词

- **禁用**：`掌握`、`学会`、`培养`、`强化` 等以"教师施动"为中心的词汇。
- **替代**：用可观测、可考核的宾语化表述——
  - ❌ "掌握数据清洗的方法" → ✅ "能独立完成缺失值、异常值的识别与处理"
  - ❌ "培养学生安全意识" → ✅ "在实操中落实数据安全与隐私保护规范"
- 教学目标与活动描述一律落到"学习者能……"的可验证行为上。
- **否定语境同样禁用**：`不要求掌握XX` 须改为 `不要求完成XX`；`尚未掌握` 须改为 `尚未能完成`。禁用词不因句式改变而豁免（实测中"不要求掌握操作"曾逃过一轮自检）。

## 4. 案例角色代称

- 案例、情境、对话中的人物**一律用代称**：`团队成员A`、`团队成员B`、`团队成员C`……
- **禁止**用 `运营专员`、`学生`、`客服`、`老师` 等真实岗位/身份词作为叙述主语。
- 代称保持前后一致；多角色场景用 A/B/C 区分职责。
- **授课对象统一称"参训者"**：教案与说课稿正文（尤其说课稿"说学情"章）不得出现"学生"，如"授课对象是高职一年级的学生"应改为"授课对象是高职一年级参训者"。
- **过程表列名统一**：路径 B 教学过程表列名用"教师活动 / 学员活动"，不用"学生活动"。

## 5. 无章节编号引用

- 正文**不得出现** `(B-1-1结论)`、`见第三章第二节`、`如 2.1 所述` 等章节编号式引用。
- 需要指代时，用自然语言重述，例如："结合上一步得到的清洗结果，……"。

## 6. 真实感要求

- 示例、案例、练习须基于**真实行业数据、真实业务表单/报表或真实工作流程**。
- 不得出现"某企业""某数据"等空泛占位；若确属虚构，须明确标注 `（示例数据）` 并说明来源类型。
- 优先使用行业通用表单（如销售日报表、库存盘点表、客户跟进记录）与公开数据集。

## 7. 编号内联

- 拓展思考、问题情境、课堂小测的编号**内联在正文段落中**，例如：
  `思考①：对比两种去重策略，说明各自适用场景。`
- **禁止**为这类编号单独建 Heading（如 `### 拓展思考1`）；它们应嵌入叙述流。

## 8. 字体（导出 Word 时执行）

- 全文统一使用**宋体**，包括标题与正文。
- 标题层级靠字号与加粗区分，不靠字体种类。
- 本条在 Markdown 阶段无法体现，交由导出 `.docx` 时统一设置（见 `SKILL.md` 转 Word 方法）。

## 9. 生成路径与教案结构

本技能有两条生成路径（判定方法见 `input-spec.md` 步骤 0），教案结构按路径选取，**章数不可混用**。

### 路径 A（岗位驱动 · 理实一体）— 九章

| 章 | 名称 | 要点 |
|----|------|------|
| 一 | 课程基本信息 | 表格须含「对应岗位（群）」「典型工作任务」两行 |
| 二 | **典型工作任务分析（岗位锚点）** | 工作过程系统化五要素：工作对象 / 工具设备 / 工作方法 / 劳动组织 / 工作要求；另写岗位能力对应与岗课赛证衔接 |
| 三 | 教学目标 | 知识目标标注"够用为度"；能力目标为主体，落到可交付成果 |
| 四 | 教学重难点 | 说明确定依据与突破方法 |
| 五 | 教学策略与资源 | 教法、学法、真实数据与行业表单模板 |
| 六 | **理实一体教学过程设计** | 表格列：教学环节 / 理论线（够用为度）/ 实践线（产出导向）/ 时间 / 设计意图 |
| 七 | **实践任务书（对接实训任务生成）** | 任务名称、任务情境、输入材料、任务要求、产出物及验收标准表、实训接口声明 |
| 八 | 板书设计 | 层级清晰，含关键词与逻辑线 |
| 九 | 作业、拓展与教学反思 | 思考①内联在正文段落中 |

### 路径 B（章节驱动 · 知识体系）— 八章

沿用 v0.1.0 结构，不变：

一 课程基本信息 → 二 教学目标 → 三 教学重难点 → 四 教学策略与资源 → 五 教学过程设计（教师活动 / 学员活动双列）→ 六 板书设计 → 七 作业与拓展 → 八 教学反思（预设）。

### 路径 A 的三条硬性要求

1. **理论线"够用为度"**：只讲本任务用得上的知识，不做学科体系化铺陈。
2. **实践线"产出导向"**：必须有可提交的产出物（清洗后数据集、业务表单、分析报告等），不能只有"练习"。
3. **验收"对标岗位"**：检查评价环节按岗位工作要求验收（可量化标准），不以教师主观判断收尾。

### 路径 A 的下游接口

第七章「实践任务书」只给**任务要求 + 产出物验收标准**，并在末尾声明"任务详情交由实训任务生成环节细化，本教案不重复展开"，与 `training-task-generator` 分工，避免内容重复。

## 10. 免责提示（三件套均须内嵌）

- 三份产物（教案 / 课件大纲 / 说课稿）均在**标题正下方**紧跟一行引用块式免责声明，不得省略。
- 标准措辞（详见 `prompts.md` 通用前置约束·免责提示）：
  - 教案：`本材料由 AI 辅助生成，请结合本校人才培养方案与真实学情二次修订后使用。`
  - 课件大纲：`本大纲由 AI 辅助生成，与《{教案文件名}》配套，后续可由 PPT 技能渲染为幻灯片。`
  - 说课稿：`本说课稿由 AI 辅助生成，内容与《{教案文件名}》自洽，适用于教学能力比赛或教研活动。`
- 该提示是"技能已内嵌免责声明"这一承诺的实际落点，缺失即为不合格产物。
