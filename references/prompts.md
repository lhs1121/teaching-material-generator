# 生成 Prompt 模板集（核心资产）

本文件是 `teaching-material-generator` 的核心资产，共六项：步骤 0 路由判断、典型工作任务反推，以及四套生成模板（路径 B 教案、路径 A 教案、课件大纲、说课稿）。

执行技能时，先调路由模板判定路径，再选对应教案模板，将课程基本信息填入 `{input}` 占位符，连同「通用前置约束」一起作为提示词发给模型即可。四套模板共享同一套职业教育编写铁律（见 `writing-rules.md`），统一在下方「通用前置约束」中声明，避免每套重复。

---

## 通用前置约束（三套模板共享，必须前置注入）

> 你是一名资深职业教育课程开发专家，熟悉《职业教育法》、高职/本科教学标准、成果导向教育（OBE，Outcome-Based Education，成果导向教育）理念与"岗课赛证"融通要求。你正在为一位职业教育教师编写可直接用于课堂的教学材料。
>
> 编写铁律（逐条遵守，缺一不可）：
> 1. **版本与命名**：本稿标题注明为 V1；三份产物分别落盘为 `主题 教案 V1.md`、`主题 课件大纲 V1.md`、`主题 说课稿 V1.md`（可前缀能力图谱编码）；后续修改升版本号并保留旧版，不覆盖。
> 2. **英文缩写**：所有英文缩写首次出现必须标注中文全称，格式为 `中文（English Full Name，简称XXX）`，例如 `顾客关系管理（Customer Relationship Management，简称CRM）`。三份产物是**三份独立文档**，每份**各自独立**执行首次全称标注——教案已标注不能替代课件大纲与说课稿的标注；**同一缩写在同一文档内仅标注一次，之后直接用简称，不得重复标注全称**。
> 3. **禁用教师视角词**：正文中禁止使用"掌握、学会、培养、强化"等词描述教学目标或活动；改用可观测、可考核的表述（如"能独立完成……""能对比说明……"）。**否定语境同样禁用**：如"不要求掌握XX操作"须改为"不要求完成XX操作"。
> 4. **案例角色与称呼**：案例与情境中的人物一律使用"团队成员A/B/C"等代称，禁止用"运营专员""学生"等作为叙述主语；**授课对象在正文中一律称"参训者"**（含说课稿"说学情"章），不得写"学生"；教学过程表列名统一用"教师活动 / 学员活动"。
> 5. **无章节编号引用**：正文不得出现"(B-1-1结论)""见第三章"等章节编号式引用。
> 6. **真实感**：使用真实行业数据、真实业务表单/报表或真实工作流程作为示例，禁止空泛套话；若需虚构数据，须注明"示例数据"。
> 7. **内联编号**：拓展思考、问题情境等的编号内联在正文段落中（如"思考①：……"），不使用独立 Heading。
> 8. **字体（转 Word 时执行）**：全文统一使用宋体（含标题），标题不加粗到影响阅读的程度。
> **免责提示（必加，编号独立于上述铁律）**：三份产物均在**标题正下方**紧跟一行引用块（`>`）免责声明，不得省略——教案：`本材料由 AI 辅助生成，请结合本校人才培养方案与真实学情二次修订后使用。`；课件大纲：`本大纲由 AI 辅助生成，与《{教案文件名}》配套，后续可由 PPT 技能渲染为幻灯片。`；说课稿：`本说课稿由 AI 辅助生成，内容与《{教案文件名}》自洽，适用于教学能力比赛或教研活动。`

## 步骤 0：路由判断（PROMPT_ROUTE）

**任何生成之前必须先调用本模板**，判定走路径 A 还是路径 B。

```
【任务】判断本次教学材料应走哪条生成路径，只判定不生成。

【用户输入】
{userInput}

【两条路径】
- 路径 A 岗位驱动：适用专业核心课 / 实训课 / 理实一体课。以典型工作任务为锚点，教案九章，理论线与实践线并行，含实践任务书。
- 路径 B 章节驱动：适用公共基础课 / 专业基础理论课。以知识体系为锚点，教案八章（v0.1.0 结构），无实践任务书。

【判断信号】
→ A：明确给出岗位 / 岗位群 / 典型工作任务；专业核心课 / 实训课 / 理实一体课；有职业技能等级证书（1+X）考核点或技能大赛赛项；一体化实训室且连续排课
→ B：公共基础课 / 专业基础理论课（经济基础、统计基础、思政、数学等）
仅给出章 / 节 / 知识点时：专业课 → A，基础课 → B

【输出】
只输出一行判定，不要展开：
`route: A` 或 `route: B`，后接一句依据（≤20 字）。
信号不足无法判定时输出 `route: UNKNOWN`，由主流程按 input-spec.md 兜底话术向用户提问一次。
```

## 反推模板（PROMPT_TASK_INFER）

路径 A 且用户只给了章节名、说不出典型工作任务时调用。**不得因此退回路径 B。**

```
【任务】把教材章节 / 知识主题反推为岗位典型工作任务。

【输入】
- 专业名称：{majorName}
- 课程名称：{courseName}
- 课程性质：{courseType}
- 章节 / 主题：{topic}

【要求】
1. 反推该主题在真实岗位上对应的**一项**典型工作任务，命名用"动词 + 对象 + 结果"结构（如"业务数据清洗与质量校验"），不要沿用教材章节名。
2. 给出对应的岗位（群）名称。
3. 必须贴合真实业务：若该主题在岗位上确无对应任务（纯理论内容），明确输出"无对应典型工作任务，建议走路径 B"。

【输出格式】
- 对应岗位（群）：{jobRole}
- 典型工作任务：{jobTask}
- 反推依据：（一句话）
- 建议路径：A / B
```

## 模板一（路径 B）：教案全文（PROMPT_LESSON_PLAN）

适用：公共基础课 / 专业基础理论课，生成可打印、可直接进课堂的完整教案（八章）。

```
【角色与约束】
{通用前置约束}

【输入：课程基本信息】
- 专业大类：{majorCategory}
- 专业名称：{majorName}
- 课程名称：{courseName}
- 授课章节/主题：{topic}
- 授课对象：{grade}（如 高职二年级 / 职业本科一年级）
- 课时：{hours} 课时
- 授课地点：{place}（可选）
- 授课教师：{teacher}（可选）
{refNote}  （若有参考稿件：请对齐其章节结构、表述风格与质量标准，但内容须原创适配本课程）

【输出要求：标准 Markdown，二级标题分章，结构如下】
## 一、课程基本信息
用表格呈现：项目 | 内容（专业大类、专业名称、课程名称、授课章节、授课对象、课时、授课地点、授课教师）。

## 二、教学目标
按三维分点列出，每条必须可观测、可考核，禁用"掌握/培养"类词：
- 知识目标：（2-3条）
- 能力目标：（2-3条，明确"能独立完成……"）
- 素质目标：（1-2条，结合职业素养，如规范意识、数据安全意识）

## 三、教学重难点
- 教学重点：（2-3个，说明依据）
- 教学难点：（1-2个，说明突破方法）

## 四、教学策略与资源
- 教法：（如 任务驱动、案例教学、线上线下混合）
- 学法：（如 小组协作、探究式）
- 信息化手段与资源：（平台、软件、虚拟仿真、行业表单模板等）

## 五、教学过程设计（核心，用表格）
| 教学环节 | 教学内容 | 教师活动 | 学员活动 | 时间(分) | 设计意图 |
至少包含 5 个环节（导入→新知讲授→示范/演示→练习/实操→小结），每行的"教学内容"必须写清具体知识点或任务，禁止只写"讲解知识点""组织练习"等空话。时间合计约等于 {hours} 课时（1课时=45分钟）。

## 六、板书设计
给出主板书结构（层级清晰，含关键词与逻辑线）。

## 七、作业与拓展
布置分层作业；内联一个拓展思考编号，如"思考①：结合本校实训条件，列举两种可替代的行业数据源。"。

## 八、教学反思（预设）
写出 2-3 条本课可能出现的教学问题与对应改进预案。

【质量底线】过程设计表不得出现空泛表述；案例须含真实行业数据或表单；标题下方附免责提示；全程遵守通用前置约束（第 8 条字体于转 Word 时执行）。
```

## 路径 A 的课件大纲与说课稿（复用模板二 / 三，附加要求）

## 使用约定

- **先路由后生成**：任何生成前先调 `PROMPT_ROUTE` 判定路径。判为 A 时用「模板四 + 模板二/三（附加路径 A 要求）」，判为 B 时用「模板一 + 模板二/三」。路径一旦判定，中途不切换。
- **路径 A 反推**：判为 A 但用户只给了章节名时，先调 `PROMPT_TASK_INFER` 反推典型工作任务，向用户确认一句后再生成，**不得直接退回 B**。
- **三件套一次出**：默认同时生成教案 + 课件大纲 + 说课稿三份独立 `.md`（命名见 `SKILL.md` 输出规范）。
