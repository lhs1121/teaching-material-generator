# teaching-material-generator

> 职业教育课堂教学材料生成器 —— 一个 [WorkBuddy](https://www.workbuddy.cn) 技能

输入课程基本信息，**一次性生成「教案全文 + 配套课件大纲 + 说课稿」三份结构化 Markdown 教学材料**，统一遵守职业教育编写铁律。适用于高职 / 职业本科的备课、教学能力比赛、教研活动。

**支持两条生成路径**（生成前自动判定，中途不切换）：

| 路径 | 适用课程 | 输入锚点 | 教案 | 特征 |
|------|---------|---------|------|------|
| **A 岗位驱动** | 专业核心课 / 实训课 / 理实一体课 | 岗位典型工作任务 | 九章 | 理论线与实践线并行；含「典型工作任务分析」「实践任务书」；按岗位工作要求验收 |
| **B 章节驱动** | 公共基础课 / 专业基础理论课 | 教材章节 / 知识主题 | 八章 | 沿用 v0.1.0 结构，无实践任务书 |

> 判为路径 A 但只给了章节名时，技能会**反推典型工作任务**并请你确认一句，不会直接退回路径 B。

## 功能特性

- **双路径自动路由**：生成前判定岗位驱动 / 章节驱动，专业课走理实一体，基础课走标准教案，各得其所。
- **三件套一次出**：默认同时产出教案、课件大纲、说课稿，内容自洽（目标 / 重难点 / 教学过程一致）；也支持按需单选其一。
- **内置 Prompt 模板**：教案（路径 A 九章 / 路径 B 八章）、课件、说课稿，另含路由判断与典型工作任务反推模板，位于 `references/prompts.md`。
- **典型工作任务反推**：只给得出章节名也能走路径 A——从主题反推对应岗位任务，确认后生成。
- **固化职业教育编写铁律**：版本号管理、英文缩写首标全称、禁用教师视角词（掌握 / 学会 / 培养 / 强化）、案例角色用 A/B/C 代称、无章节编号引用、真实行业数据——见 `references/writing-rules.md`。
- **可选参考稿件对齐**：提供主编认可稿件时，自动对齐其结构与质量标准。
- **内嵌免责提示**：每份产物标题下方自动附 AI 生成免责声明，可直接进入教研流程。
- **零外部依赖**：产物为纯 Markdown，任何人都能用；**自带 `scripts/md2docx.py` 一键批量转 Word**（自动统一宋体、表格补边框），转法见下文。
- **网页版工作台**：`docs/index.html` 单文件，整门课一次填表 → 输出一段可直接粘贴的规范请求文本；可本地双击打开，也可通过 GitHub Pages 在线访问，见下文。

## 网页版工作台（整门课批量备课）

对话式提问适合单章节，**整门课十几个章节**时来回问十几轮很慢。`docs/index.html` 是这个场景的填表工具：课程级信息填一次，章节级按行补充，实时吐出规范请求文本，粘进 WorkBuddy 对话框即可。

- **在线访问**：<https://lhs1121.github.io/teaching-material-generator/>（仓库 Settings → Pages → Source 选 `master` 分支的 `/docs` 目录）
- **本地打开**：双击 `docs/index.html`（单文件、零依赖，不联网也能用）

**它只做"把话说明白"，不做判断**——路由判定（岗位驱动 / 章节驱动）与典型工作任务反推仍然交给技能。工作台在输出文本里明确写上"未填典型工作任务时请整批反推后一次性列出"，让批量场景只需确认一次，而不是逐章追问。

填写内容存于本机浏览器（localStorage），刷新不丢。

## 用法

在 WorkBuddy 对话中表达备课意图即可触发，例如：

> 帮我校《商务数据分析》的"数据清洗与预处理"那章做个教案和课件，高职大二，4 学时。

技能会**先判定路径**（本课为专业核心课 + 4 学时连续排课 → 路径 A 岗位驱动），再补齐以下信息后生成：

| 字段 | 必填 | 说明 |
|------|------|------|
| 专业大类 | ✅ | 如 财经商贸大类 |
| 课程名称 | ✅ | 如 商务数据分析实务 |
| 授课章节 / 主题 | ✅ | 如 数据清洗与预处理 |
| 授课对象 | ✅ | 如 高职二年级 |
| 课程性质 | ⚠️ | 决定走哪条路径，如 专业核心课 / 公共基础课 |
| 对应岗位（群） | ⚠️ 路径 A | 如 商务数据分析师 / 数据运营 |
| 典型工作任务 | ⚠️ 路径 A | 如 业务数据清洗与质量校验（可反推） |
| 课时 | ⚠️ 默认 2 | 如 4 |
| 授课地点 / 教师 / 参考稿件 | ❌ 可选 | 地点、教师给默认，参考稿用于对齐风格 |

## 与其他职业教育技能的关系

本技能与以下两个技能互补，构成"岗课赛证"融通的课程开发工具链：

- `vocational-competency-map` —— 能力图谱（顶层设计：定"教什么"）
- **`teaching-material-generator`**（本技能）—— 课堂教学设计（解决"怎么教"）
- `training-task-generator` —— 实训任务（实践教学：解决"怎么练"）

**路径 A 的衔接接口**：第七章「实践任务书」指向 `training-task-generator`——本技能只给任务要求与产出物验收标准，任务详情（数据集字段说明、分步操作指引、评分细则）交由实训任务生成环节细化，两者内容不重复。

| 路径 | 产物 | 结构 | 命名 |
|------|------|------|------|
| **A 岗位驱动** | 教案全文 | 课程基本信息 → **典型工作任务分析** → 教学目标 → 重难点 → 策略 → **理实双线过程设计表** → **实践任务书** → 板书 → 作业拓展与反思（九章） | `<典型工作任务名> 教案 V1.md` |

## 转 Word（可选）

产物为 Markdown，便于审阅与版本管理。需 `.docx` 时，**用自带脚本**，一条命令批量转换：

```bash
python scripts/md2docx.py --out dist "主题 教案 V1.md" "主题 课件大纲 V1.md" "主题 说课稿 V1.md"
```

依赖 `pandoc` + `python-docx`。脚本自动完成三件事：

1. pandoc 转换，保留标题层级、表格与列表结构；
2. **统一全局字体为宋体**（含标题、表格内文字），标题按层级设字号、颜色归黑——落实编写铁律第 8 条；
3. 表格补齐边框，首行设为重复表头（跨页时自动重复）。

教案「板书设计」章是 ASCII 树形图（Markdown 代码块），默认同样设宋体；**若在 Word 中树形图对齐错乱，加 `--code-font Consolas`**。

转换后跑校验脚本，程序化确认铁律第 8 条：

```bash
python scripts/verify_docx.py dist/*.docx
```

输出每份文档的段落 / 标题 / 表格数量、**非宋体 run 数（应为 0）**、表格边框与行列结构。

若环境已安装 `tencent-docx` 技能，也可直接调用其生成排版后的 Word。
