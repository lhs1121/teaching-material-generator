## 三、教学目标

- **知识目标（够用为度）**：
  - 能说明数据清洗在抽取-转换-加载（Extract-Transform-Load，简称ETL）流程中的位置与作用；
  - 能列举缺失值、异常值、重复值三类常见问题及其业务成因。
- **能力目标（本任务主体）**：
  - 能依据数据质量四维度对一份真实电商订单数据完成逐项核查；
  - 能使用电子表格或 Python（pandas 库）完成缺失值填充、异常值修正与重复值剔除；
  - 能输出清洗后数据集与《数据质量核查与处理记录表》，并说明每步处理依据。
- **素质目标**：
  - 在实操中落实数据安全与隐私保护规范，对个人手机号等敏感字段做脱敏处理；
  - 形成"先探查、后处理、留痕可溯"的数据处理职业习惯。

## 四、教学重难点

- **教学重点**：缺失值与异常值的识别方法及处理策略。
  - 依据：这两类问题在真实业务数据中占比最高，直接决定后续分析结论的可靠性。
- **教学难点**：异常值判定阈值的合理确定（如订单金额上下限）。
  - 突破方法：业务规则（平台客单价分布、退货金额符号）与统计方法（3σ 原则）双视角对比，由团队成员在实训中自行验证后确定阈值，教师不预先给定。

```
├─ 怎么洗：ETL 之 T 阶段（脱敏！）
└─ 交什么：数据集 + 记录表 + 诊断说明（留痕可溯）
```

## 九、作业、拓展与教学反思

- **基础作业**：下载课后数据集（某连锁超市销售明细），独立完成四维度核查与缺失值、重复值处理，提交清洗后文件与记录表。
- **提升作业**：对"会员消费金额"列分别用 3σ 原则与业务规则法识别异常值，对比两种方法的适用边界并写出结论。
- 思考①：结合本校实训条件，列举两种可替代的本地数据源（如校园一卡通消费记录、图书馆借阅日志），说明其清洗要点的差异。

**教学反思（预设）**：

- 风险点：参训者对异常值阈值易武断设定，可能直接删除所有极值。改进预案：任务实施环节强制先写判定依据再操作，教师抽样点评。
- 风险点：敏感字段脱敏意识薄弱。改进预案：任务导入环节即强调《个人信息保护法》要求，将脱敏纳入验收标准而非提示项。
- 亮点（可用于说课）：以真实岗位典型工作任务为主线，理论线"够用为度"、实践线"产出导向"，验收对标岗位工作要求而非教师主观判断，契合理实一体化与岗课赛证综合育人要求。
