## 三、教学目标

- **知识目标**：
  - 能说明数据清洗（Data Cleaning）在 ETL（Extract-Transform-Load，抽取-转换-加载）流程中的位置与作用；
  - 能列举缺失值、异常值、重复值三类常见问题及其业务成因。
- **能力目标**：
  - 能使用电子表格或 Python（pandas 库）对 CSV（Comma-Separated Values，逗号分隔值）文件完成缺失值填充、异常值修正与重复值剔除；
  - 能针对一份真实电商订单数据输出清洗后的可用数据集，并说明每步处理的依据。
- **素质目标**：
  - 在实操中落实数据安全与隐私保护规范，对个人手机号等敏感字段做脱敏处理；
  - 形成"先探查、后处理、留痕可溯"的数据处理职业习惯。
- **课程思政融入点**：

| 思政元素 | 融入知识点/环节 | 融入方式 |
| --- | --- | --- |
| 数据安全与隐私 | 敏感字段脱敏环节 | 以《中华人民共和国个人信息保护法》条款强调手机号脱敏，纳入实操评分项 |
| 数据真实性（诚信） | 异常值处理环节 | 设问"能否为让数据好看而随意删改异常值"，辨明"清洗≠篡改"的边界 |
| 工匠精神 | 处理留痕环节 | 以"每条处理写清依据、结果可追溯"体现精益求精 |
| 责任担当 | 案例导入环节 | 用"脏数据误导经营决策"的真实事故，强调数据岗对结论负责 |

## 四、教学重难点

- **教学重点**：缺失值与异常值的识别方法及处理策略。
  - 依据（含学情分析结论）：据课前小测，参训者基础处理尚可、判定依据薄弱；且这两类问题在真实业务数据中占比最高，直接决定后续分析结论的可靠性。
- **教学难点**：异常值判定阈值的合理确定（如订单金额上下限）。
  - 突破方法：引入业务规则（如平台客单价分布、退货金额符号）与统计方法（3σ 原则）双视角对比，由团队成员在实训中自行验证，教师不预先给定。

## 五、教学策略与资源

- **教法**：任务驱动 + 案例教学 + 线上线下混合（课前微课自学概念，课中实战）。
- **学法**：小组协作（3 人/组，角色分工见下文）、探究式验证。
- **信息化手段与资源**：
  - 实训平台：商务数据分析实训系统（在线环境，免安装）；
  - 数据：某电商"双11"订单明细表（脱敏样本，含 2000 行）；
  - 表单模板：《数据质量检查表》《清洗处理记录表》。

## 七、板书设计

```
数据清洗与预处理
├─ 为什么洗：质量→结论可信（案例：ROI +40% 误判）
├─ 洗什么
│   ├─ 缺失值（NaN）：删除 / 填充 / 标记
│   ├─ 异常值：业务规则 + 统计(3σ) 双判定
│   └─ 重复值：按唯一键去重
├─ 怎么洗：ETL 之 T 阶段（脱敏！）
└─ 留痕：《清洗处理记录表》可追溯
```

## 八、作业与拓展

- **基础作业**：下载课后数据集（某超市销售明细），独立完成缺失值与重复值处理，提交清洗后文件 + 处理记录表。
- **提升作业**：对"会员消费金额"列用 3σ 原则识别异常值，并与业务规则法对比，写出两种方法的适用边界。
- 思考①：结合本校实训条件，列举两种可替代的本地数据源（如校园一卡通消费记录、图书馆借阅日志），说明其清洗要点差异。

## 九、教学反思（预设）

- 风险点：参训者对"异常值阈值"易武断设定，可能直接删除所有极值。改进预案：在练习环节强制要求先写判定依据再操作，教师抽样点评。
- 风险点：敏感字段脱敏意识薄弱。改进预案：导入即强调《个人信息保护法》要求，将脱敏纳入实操评分项。
- 亮点（可用于说课）：以"真实事故案例"导入，把数据质量从"技术规范"上升为"职业责任"；学情分析以数据支撑引出重难点，课程思政从专业知识自然提炼，契合素养目标。
